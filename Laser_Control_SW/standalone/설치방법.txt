========================================================
 Tamadenshi 레이저 제어 소프트웨어 — 설치 안내
========================================================

[ 설치 방법 ]

터미널을 열고 압축을 푼 폴더에서 아래 한 줄만 실행하세요.

    ./install.sh

시스템 패키지 설치, 파이썬 환경 구성, USB 권한 등록,
응용프로그램 메뉴 등록까지 전부 자동으로 진행됩니다.

권한 오류가 나면 먼저 실행 권한을 주세요.

    chmod +x install.sh && ./install.sh


[ 설치 후 반드시 해야 할 일 ]

  ★ 레이저의 USB 케이블을 뽑았다가 다시 꽂으세요. ★

  새로 등록된 USB 권한 규칙이 적용되려면 필요한 과정입니다.
  이 과정을 건너뛰면 보드를 찾지 못합니다.


[ 실행 방법 ]

  · 응용프로그램 메뉴에서 "Laser Control" 실행
  · 또는 터미널에서:  ./run_gui.sh


[ 필요 환경 ]

  · Ubuntu 20.04 이상 (또는 apt 기반 리눅스)
  · 인터넷 연결 (설치 시 패키지 다운로드에 필요)
  · sudo 권한

  인터넷이 안 되는 PC라면 설치가 실패합니다.
  그 경우 담당자에게 오프라인 설치본을 요청하세요.


[ 다른 설치 옵션 ]

  ./install.sh --no-gui     GUI 없이 명령줄 도구만 설치
  ./install.sh --no-sudo    관리자 권한 없이 설치 (USB 권한은 수동 설정 필요)


[ 참고 ]

  · 자세한 사용법은 README.md 파일을 참고하세요.
  · laser_control_installer.sh 는 이 폴더 전체를 하나로 묶은
    파일입니다. 폴더 없이 이 파일 하나만 있어도 설치가 가능하며,
    실행하면 ~/laser_control 에 설치됩니다.
  · 메인 통합 프로그램(main.py)이 레이저에 연결되어 있으면
    이 프로그램은 연결할 수 없습니다. 한 번에 하나만 사용됩니다.
